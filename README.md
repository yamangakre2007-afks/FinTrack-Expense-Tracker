💰 FinTrack – Expense Tracker

FinTrack is a simple and responsive expense tracking web application built using HTML, CSS, and JavaScript.

It helps users record, manage, and monitor their daily expenses through an interactive dashboard.

🚀 Live Demo

Live Website: https://fintrack-phi-bay.vercel.app/

GitHub Repository: https://github.com/yamangakre2007-afks/FinTrack-Expense-Tracker

🚀 Features

* Dashboard: View total expenses, monthly expenses, and total transactions.
* Add Expenses: Record expenses with title, amount, category, and date.
* Edit Expenses: Update existing expense details.
* Delete Expenses: Remove unwanted transactions.
* Search: Search expenses by title.
* Category Filter: Filter transactions by category.
* Sorting: Sort expenses by date and amount.
* Dark Mode: Switch between light and dark themes.
* Local Storage: Save expense data in the browser.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
* Font Awesome
